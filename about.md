# About This Website

This website is a personal portfolio built as a cinematic single-page experience. It presents JZ as a student, creator, and digital curator through bold typography, layered motion, and a highly art-directed layout.

## What It Is

The site is designed to feel more like an editorial or gallery piece than a standard portfolio. It mixes personal branding, visual storytelling, and interactive motion to create a polished introduction to the person behind the work.

## Main Sections

- Hero: a high-impact opening section with oversized type, a brand statement, and scroll-based parallax.
- About: a profile section that explains the design philosophy and creative approach.
- Timeline: a journey section for milestones, experience, or growth.
- Toolkit: a curated view of skills, interests, and disciplines.
- Polaroid Strip: a horizontal visual gallery that adds personality and texture.
- Contact: a direct call to action with email and external links.
- Footer: the closing section that wraps up the page.

## Key Features

- Smooth scrolling powered by Lenis for a refined, fluid feel.
- Scroll-based motion and parallax effects using Motion.
- Animated glitch-style typography for visual emphasis.
- A layered 3D background with floating elements and frames.
- Custom cursor behavior for a more immersive interaction model.
- Sticky navigation and a section rail for quick movement through the page.
- An embedded music player that adds a personal, ambient layer.
- Responsive layout that adapts across desktop and mobile widths.

## UI and Visual Style

The UI follows a luxury-editorial direction with deliberate spacing, large type, uppercase labels, and strong contrast. It uses dark tones, gold/brass accents, and subtle translucent surfaces to create a moody presentation.

The design language emphasizes:

- Bold display typography.
- Monospace and uppercase microcopy for structure.
- Heavy use of whitespace and rhythm.
- Subtle borders, glows, and transparent panels.
- Motion that supports the content instead of overwhelming it.

## Interaction Design

The page is built around layered motion rather than heavy navigation. Content reveals as the user scrolls, and many elements respond with scale, opacity, position, or tracking changes. The goal is to make the experience feel curated and alive while keeping the content readable.

## Technical Stack

- Vite for the build system.
- React for the UI.
- TypeScript for type safety.
- Motion for animation and scroll-linked effects.
- Lenis for smooth scrolling.
- Three.js and React Three Fiber for 3D visuals.
- Tailwind CSS for styling.

## Deployment

The project is set up to deploy to GitHub Pages. The build output uses a relative base path so assets resolve correctly when hosted under the repository subpath.

## Overall Goal

The site is meant to communicate taste, technical polish, and personality at the same time. It is less about showing many projects and more about making the portfolio itself feel like a finished creative artifact.
